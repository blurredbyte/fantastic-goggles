## Practical Demo: Implementing secure logging and error handling

This module includes a practical demonstration of insecure error handling. The code for this demo can be found in the `module7_error_handling_and_logging_demo` directory. The demo showcases a web application that leaks sensitive information, such as full file paths and code snippets, in its error messages when running in debug mode.
