## Practical Demo: Fortifying against CSRF in SPAs

This module includes a practical demonstration of a Cross-Site Request Forgery (CSRF) vulnerability. The code for this demo can be found in the `module9_csrf_demo` directory. The demo showcases a web application with a settings page that is vulnerable to CSRF, allowing an attacker to trick a user into changing their settings unintentionally. It also demonstrates how to mitigate this using CSRF tokens.
