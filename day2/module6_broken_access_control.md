# Module 6: Broken Access Control

*   Manage user sessions with multi-factor authentication (MFA) best practices.
*   Implement secure cookie attributes across modern browsers.
*   Deploy advanced OTP, CAPTCHA, and adaptive authentication methods.

## Practical Demo: Locking down access control in complex apps

This module includes a practical demonstration of a broken access control vulnerability, specifically an Insecure Direct Object Reference (IDOR). The code for this demo can be found in the `module6_broken_access_control_demo` directory. The demo showcases a web application where a user can access resources belonging to other users by simply changing an ID in the URL.
