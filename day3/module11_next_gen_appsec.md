# Module 11: Next-Gen Application Security

*   **Secure coding standards: OWASP ASVS:** Learn how to use the OWASP Application Security Verification Standard (ASVS) as a benchmark for application security.
*   **Use of AI/ML in static analysis:** Explore how artificial intelligence and machine learning are being used to improve the accuracy and speed of static analysis security testing (SAST) tools.
*   **Securing CI/CD pipelines:** Understand the principles of DevSecOps and learn how to embed security into your Continuous Integration and Continuous Deployment pipelines.

## Practical Demo: Integrating security scanners in CI

This module includes a practical demonstration of how to integrate an automated security scanner into a CI/CD pipeline. The demo can be found in the `module11_next_gen_appsec_demo` directory. It showcases a simple GitHub Actions workflow that automatically scans code for hardcoded secrets on every push, preventing them from ever being committed to the main branch. This is a foundational practice for securing the software supply chain.
