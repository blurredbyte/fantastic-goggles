# Module 12: CTF - Secure Source Code Review

*   **Engage in guided practice:** Apply the knowledge you've gained throughout the course in a hands-on Capture The Flag (CTF) event.
*   **Walk through real-world scenarios:** Analyze a custom-built web application that contains multiple, realistic security vulnerabilities.
*   **Collaborate on code reviews:** Work with your peers to perform a secure code review, identify flaws, and suggest fixes.

## Practical Demo: The "h1hakz" CTF Challenge

This module is a hands-on Capture The Flag (CTF) challenge. The goal is to perform a secure code review of a small web application and identify as many vulnerabilities as you can.

The application code and instructions for the CTF can be found in the `module12_ctf_demo` directory.

The application is intentionally riddled with several of the vulnerabilities discussed in this course, including (but not limited to):
*   Injection flaws
*   Broken access control
*   Hardcoded secrets
*   And more...

Your task is to review the Python Flask code, find the security bugs, and document your findings. For each bug, you should identify the vulnerable code, explain the risk, and recommend a mitigation. Good luck!
