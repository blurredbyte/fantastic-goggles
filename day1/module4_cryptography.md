## Practical Demo on Cryptography

This module includes a practical demonstration of cryptographic weaknesses. The code for this demo can be found in the `module4_cryptography_demo` directory. The demo showcases examples of weak hashing (e.g., unsalted MD5) versus strong, modern hashing techniques for storing passwords.
