# Module 2: Insecure Design Flaws

*   Spot and fix design flaws common in modern apps.
*   Implement secure design controls using zero-trust principles.
*   Use Confidentiality, Integrity, and Availability (CIA) for risk assessments.

## Practical Demo: Insecure Design Flaw

This module includes a practical demonstration of an insecure design flaw. The code for this demo can be found in the `module2_insecure_design_demo` directory. The demo showcases a simple web application where access control is improperly handled on the client-side, making it easy to bypass.
