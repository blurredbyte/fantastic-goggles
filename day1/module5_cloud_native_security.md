# Module 5: Secure Coding for Cloud-Native Applications

*   Cloud-specific security considerations (shared responsibility model, API security, etc.)
*   Securing containerized applications (Docker, Kubernetes)
*   Serverless security (Google cloud run, Google Kubernetes Engine)

## Practical Demo on Infrastructure as Code analysis

This module includes a practical demonstration of an insecure Dockerfile. The code for this demo can be found in the `module5_cloud_native_security_demo` directory. The demo showcases a `Dockerfile` with several common security misconfigurations, such as running as root, hardcoded secrets, and using an outdated base image.
