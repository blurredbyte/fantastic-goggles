## Practical Demo: Safeguarding against injection attacks

This module includes a practical demonstration of a SQL injection vulnerability. The code for this demo can be found in the `module3_injection_demo` directory. The demo showcases a simple web application that is vulnerable to SQL injection because it uses unsafe string formatting to build SQL queries.
